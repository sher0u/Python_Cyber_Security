# Python Cyber Security

This repository is my practical journey of refreshing **Python through Cybersecurity**.

The goal is not only to review Python syntax, but to use Python to build practical tools for **network reconnaissance, web security, automation, reverse engineering, and penetration testing**.

I will document what I learn, build the tools myself, and keep the projects organized so the repository can serve as both a learning record and a cybersecurity portfolio.
